# P2b 地域 vs 条块：一页结论

2026-10-10。P2 的第一项待办。P2 的零模型只在落款年内重排位置标签，所以"同系统同层级"和"同一个地方"混在一起：
同一个县的两名村干部既是格内，也是同乡。P2b 用两件工具把它们分开。代码 `scripts/p2b_geography.py`（85 秒），
全部数表见 `p2b_tables.md`，图 `fig5_strata.png`、`fig6_place.png`。

**口径。** 与 P2 相同：5,661 份文书、16,031 名被告人、47 个系统×层级节点、边权 1/(n−1)。
(1) **分层零模型**：把重排限制在 年×省（121 块）、年×地级市（1,027 块）、年×起诉院（3,362 块）之内，重排时位置
标签和单位所在地一起走。只有一份文书的块无法重排（单份文书内部怎么换，边的集合都不变），起诉院一级只有 63% 的
边权重能动，所以另报"仅可重排"的版本。
(2) **单位所在地**：用 P1 从单位名里写出的地名解析出的 `position_region_code`（55% 定到县、12% 到市、6% 到省、
27% 不明），给每条边标 同县 / 同市异县 / 同省异市 / 异省 / 同市(县不明) / 同省(市不明) / 不明，与条块关系交叉。

## 七条结论

**1. 地域混淆是真的，而且大。** 格内份额的零模型期望随分层变严单调上升：年 13% → 省 16% → 地级市 27% → 起诉院
42–51%。观测的 66% 在每一层都显著高于期望（z +65 到 +205），但"高出几倍"从 5 倍缩到 1.3–1.6 倍。

**2. "块 > 条 > 跨"大半是地域效应。** 跨出本格后的条件倍数 块 : 条 : 跨，从 3.5 : 1.9 : 0.6（年）→ 2.4 : 1.6 : 0.7
（地级市）→ 1.4 : 1.3 : 0.8（起诉院）。看无条件份额更清楚：地级市分层后，**同块份额恰好等于零模型**（0.048 对
0.049，z 0），同条低于零模型（0.049 对 0.072，z −12），跨远低于（0.092 对 0.336，z −84）。所以净去地域后能站住的
是：同一类单位内部的共谋是本地随机配对的 2.5 倍，系统层级都不同的共谋只有 0.3 倍，同层级跨系统的共谋与本地随机
配对相当，上下级共谋比本地随机还少。"块优于条"只在"既然跨出本格"的条件意义上成立，而且到起诉院一级几乎抹平。
它不能再作为主要发现。

**3. 分层后层级与罪名的差别缩小一半，方向不变。** 地级市分层下：省、市层级 条 > 块（2.1 对 1.0，2.0 对 1.5），
县、区 块 ≥ 条（1.8 对 1.7，2.1 对 1.8），乡镇街道 1.4 对 1.5。贿赂和渎职仍是最"块"的罪名（块 2.5、2.8，条 1.8），
贪污挪用 块 2.0、条 1.4，"其他"条 2.9、块 1.1。

**4. 同案被告的地域性在县一级，地级市分层控制不住，起诉院分层又过严。** 两端都定到县的 9,066 对边里 97.4% 同县；
年×地级市零模型对"同市异县"的期望权重约 1,690，观测只有 19。一个地级市里不同县的人几乎不会同案，所以地级市分层
仍然高估了随机配对的跨县部分；起诉院分层能控住（定到县的位置 88% 就是起诉院所在县），但 37% 的边动不了，零模型
天然偏向观测。真值在两行之间：格内倍数 1.5–2.5，块的条件倍数 1.4–2.4，条 1.3–1.6。

**5. 系统的自配对倍数全面缩水，隔离格局不变。** 年×地级市下的自配对（括号内为 P2 按年值）：党委 3.7 (13.5)、
人大政协 4.5 (45)、公检法司 4.1 (27)、金融 5.4 (37)、事业 3.1 (9.2)、民营 2.9 (9.0)、国企 2.5 (6.3)、无公职 1.9 (5.1)、
村级 1.9 (2.8)、政府 1.9 (2.6)。所有系统自配对仍 > 1，跨系统配对绝大多数仍 < 1；村级组织与其他系统 0.09–0.65，仍是
封闭簇（介数 z −121）。升到 1 以上的跨系统配对只有 金融–党委 1.5、人大政协–民营 1.4、人大政协–无公职 1.6，都是小
样本；公检法司–无公职、民营–无公职升到 0.99。

**6. 桥的名单变了一半。** 介数 z（年 → 年×地级市）：无公职 +19 → +17，国企|省 +9 → +12，这两个不受地域影响；
政府部门的桥接地位减半：区 +12 → +7，乡镇街道 +9 → +5，市 +10 → +3，县 +4 → +3；国企|市 +6 → +2；
事业单位|不明 +18 → +7。P2 的"桥在无公职和政府部门"要改成"桥在无公职和省级国企，政府部门的桥接大半是同一个
地方的党政事企同案"。

**7. 直接按单位所在地看，结论一致。** 同县的边占权重 48%，其格内份额 80% 对零模型 65%（z +16），跨出本格后条、块
各 1.4 倍、跨 0.8 倍——同县之内条块无差别。异地的边（同市异县 + 同省异市 + 异省）合计权重 74，不到 1%，只能描述。
格内权重的构成：同县 58%、同市(县不明) 11%、同省(市不明) 5%、不明 25%、异地 < 1%。

## 对 P2 五条结论的修订

| P2 结论 | P2b 之后 |
|---|---|
| 1 格内化（66% 对 13%） | 成立；倍数改报 2.5 倍（地级市）到 1.5 倍（起诉院） |
| 2 块 > 条 > 跨（3.5 / 1.9 / 0.6） | 降级：条件意义上在地级市分层下仍成立（2.4 / 1.6 / 0.7），到起诉院几乎消失；无条件意义上同块 = 本地随机，同条 < 本地随机 |
| 3 村级组织自成簇（2.8×） | 成立；1.9×，仍与所有其他系统 < 1 |
| 4 桥在无公职和政府部门 | 改写：无公职与国企|省稳健，政府部门各层级减半 |
| 5 显著高于零模型的配对都是同一地方的党政事企 | 这正是地域效应本身；分层后的配对倍数见 `p2b_sys_matrix_city.csv` |

## 保留

1. 起诉院分层的零模型有 37% 的边权重在单文书块里不能动，这部分观测 = 零模型；"仅可重排"行去掉了这些边，但样本
   随之变化。地级市分层是能完整重排的最细粒度，但按结论 4 它仍低估地域效应。
2. 单位所在地只来自单位名；无公职和打码单位不明（35% 的权重）。能定到县的位置 88% 就是起诉院所在县，所以"同县"
   与"同院"几乎是一回事，位置所在地没有提供起诉院区划以外的多少信息。
3. 分层零模型控制的是"同一个地方的被告人池"，不控制"同一个单位"：同一个局的两名科员在任何零模型下都是格内。
   格内 66% 里有多少是单位内部，要等单位名消歧（P1 的 `position_org` 带打码）或 L2。
4. 分层后多数节点的介数在零模型里恒为 0（表 D 的 nan），介数 z 只对十来个大节点有意义。

## 含义

P2 的条块对比（块 vs 条）不是一个稳健的发现；稳健的是单位类型内部的封闭性和系统之间的隔离，而这两点与"窝案一起
起诉"的办案方式难以区分（P2 保留 1）。这加强了 2026-10-10 下午的判断：这条线的核心应放在中间人（谁在系统之间、
层级之间搭桥，桥沿条还是沿块），L1 的条块份额只做背景。P3 建议不变：标中间人三元组，不做泛用 L2/L3 黄金集。
